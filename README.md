# Restaurant Management System

A Python Full Stack Web Application developed to simplify restaurant operations and enhance the customer dining experience. The application integrates a frontend interface with a Python Flask backend to support restaurant-related functionalities.

## Technologies Used

- **Frontend:** React.js, HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Package Manager:** npm, pip

## Installation and Execution

**Frontend**
```bash
cd frontend
npm install
npm run dev
```

**Backend**
```bash
cd backend
python -m pip install flask
python app.py
```

## Key Functionalities

- Restaurant menu browsing
- Online food ordering
- Advance table reservations
- Food recipe viewing
- Frontend and backend integration

## Project Objective

To develop a full-stack restaurant application using Python and Flask for backend development and React.js for frontend development, providing a convenient platform for restaurant customers.
